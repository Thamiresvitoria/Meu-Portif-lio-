# 🖥️ Portifólio 

 ## Descrição do Projeto

Este portfólio foi desenvolvido inicialmente como parte de uma atividade avaliativa do curso Técnico em Análise e Desenvolvimento de Sistemas da ETE Cícero Dias. Como o projeto ainda possuía alguns ajustes pendentes após sua conclusão inicial, aproveitou-se a oportunidade para realizar melhorias e refinamentos durante a graduação em Análise e Desenvolvimento de Sistemas.

A proposta da disciplina na faculdade consistia em criar um novo projeto ou aprimorar um projeto já existente. Dessa forma, optou-se por evoluir o portfólio previamente desenvolvido, realizando melhorias na estrutura, estilização e funcionalidades implementadas.

O desenvolvimento do projeto utilizou inicialmente as tecnologias HTML, CSS e JavaScript, servindo como uma atividade prática voltada ao estudo, experimentação e consolidação dos conhecimentos adquiridos ao longo da formação.

## Melhorias Pendentes

Atualmente, algumas melhorias ainda estão previstas para futuras versões do projeto:

- Melhorar a responsividade para diferentes tamanhos de tela;
- Adicionar novos projetos ao portfólio;
- Aprimorar o design e a experiência visual da interface.
